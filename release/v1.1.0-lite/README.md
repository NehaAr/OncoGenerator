# Dataset card - OncoGenerator-Endo v1.1.0

## Summary
Fully synthetic clinical and proteomic data for endometrial cancer, produced by the open-source OncoGenerator generator, with machine-readable ground truth. Intended for benchmarking analysis methods and for teaching, where real patient data cannot be shared.

## Contents
- `core_n1000`, `core_n10000`, `core_n100000`: default scenario, seeds 1, 2, 3.
- `scenario_*_n10000`: noise_low, noise_high, imbalanced_late10, batch5, missing_mcar10, missing_mnar20 (seed 2).
- Per dataset: `clinical`, `proteins_log2fc` (180 proteins), `ground_truth_proteins`, `ground_truth_contrasts`, `run_metadata.json`; plus `expected_log2fc_noise_free` for the 1k and 10k core cohorts; `ground_truth_batch_effects` for batch5.
- `data_dictionary.json`, `manifest.json` (SHA-256 of every file).
- Size: ~80 MB as csv.gz. Static; new versions are separate releases.

## Intended uses
Benchmarking differential-expression, feature-selection and classification methods with known truth; testing sensitivity to noise, class imbalance, batch effects and missing values; teaching; pipeline and software testing; demonstrating privacy-safe data sharing.

## Not intended for
Drawing biological or clinical conclusions; estimating real-world model performance; training models for clinical use.

## Limitations (read before use)
- Effect sizes and directions are simulation settings taken from a hand-compiled dictionary whose original lists had unequal lengths; alignment against the literature is unverified (see README).
- Stage and grade scale the effects by construction, so stage prediction from proteins is easy and unrealistic.
- `Treatment`, `Myometrial_mm`, `Ethnicity` are independent noise; `Survival_Outcome` is derived from stage/grade (leakage if used to predict stage).
- Clinical marginals were designed to resemble Australian registry statistics; the formal comparison reported in the manuscript was not re-run for this release.
- Pathway correlation is a single latent factor per pathway.
- For the menopause and tumour-type contrasts the `is_nonzero_effect` flag is nearly always true (indirect associations); use `true_effect_log2fc` / `is_large_effect`.
- Batch effects are added after the [-3, 3] clip, so batch5 values can exceed +/-3.

## Provenance and licensing
Generated by code in https://github.com/NehaAr/OncoGenerator (MIT). Data released under CC BY 4.0. Per-protein annotations `normal_tissue_regulation_hpa` and `prognostic_flag_hpa` are derived from the Human Protein Atlas (CC BY 4.0; Uhlen et al., Science 2015), whose TCGA-UCEC prognostic analysis is itself based on TCGA open-access data. No individual-level TCGA, UK Biobank or other patient data are included.

## Reproducibility
`python scripts/build_release.py` rebuilds every file deterministically (generator v1.1.0, seeds in `manifest.json`). Parquet versions: `python scripts/build_release.py --format parquet` (needs pyarrow).
